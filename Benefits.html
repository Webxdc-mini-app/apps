What is Webxdc?

ミニアプリ（Webxdc）とは？

HTML / JavaScriptで作られた小さなアプリを、デルタチャットの会話の中でそのまま動かす仕組みです。実体は .xdc = ZIP（index.html, CSS, JS, manifest.toml, icon）。デルタチャットがネットワーク遮断したWebViewで実行し、データ共有はチャット自体のメール配送で行います。

my-app.xdc (ZIP) ├─ index.html → <script src="webxdc.js"> ├─ app.js / style.css ├─ manifest.toml └─ icon.png ※ webxdc.jsはDelta Chatが注入

Architecture

従来型とWebxdcで何が違う？

従来のWebアプリ / LINEミニアプリ

ユーザー ↔ クラウドサーバー/DB ↔ ユーザー
  • サーバー・DB・ドメインが必須、維持費がかかる
  • 個人情報が外部サーバーへ、トラッキングの懸念
  • ネットが切れると停止、閉域網では使えない

Delta Chat + Webxdc

ユーザー → メール配送(E2E) → ユーザー
チャットがトランスポート
  • 専用アプリサーバー不要、.xdcを送るだけで即利用
  • ネットワーク遮断により、アプリからの外部通信を防止
  • ローカルSMTP/IMAP、メッシュWi-Fiでも動作
同期の仕組み：sendUpdate / setUpdateListener

[端末A] sendUpdate({payload:{vote:"A"}, info:"Kawaさんが投票"}) 
        ↓ Delta Chatのメール配送 (SMTP/IMAP + E2E暗号化)
[端末B] setUpdateListener((updates)=>{ render(updates) })
        ↓ チャットには info が「Kawaさんが投票しました」と履歴表示

payloadは任意のJSON。通信コードを書かなくても全員に届く。

Webxdcアプリからの外部通信を制限し、 トラッキングリスクを大幅に低減。

☁️✕

社内LAN、工場ネットワーク、避難所のメッシュWi-Fi、イベント会場。ネットがなくても動く。

📦

📱

⑥ ストア不要・全OS対応

Android / iOS / Windows / macOS / Linuxで同一動作。App Store審査なしで社内配布も自由。

Note

知っておきたいこと

  • サイズは軽量に：メール添付で配布するため数MB以内推奨
  • 外部通信不可：プライバシーの代わりに外部APIは呼べない
  • 更新は再配布：新しい.xdcをチャットに送り直す
  • 保存は自前：localStorageやsendUpdate履歴から復元する設計に
